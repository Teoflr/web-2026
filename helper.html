📝 HTML Fundamentals Refresher

🏷️ What are HTML Tags?

HTML tags are keywords surrounded by angle brackets that define the structure and content of web pages. They usually come in pairs: an opening tag and a closing tag.

Basic Tag Structure:

<tagname attribute="value">Content goes here</tagname>
  • <tagname> - Opening tag
  • attribute="value" - Optional attributes
  • Content - Text or other HTML elements
  • </tagname> - Closing tag (note the forward slash)

🏗️ Document Structure

Essential HTML5 Document Structure 
<!DOCTYPE html>
<html lang="en">

<!DOCTYPE html> - Tells browser this is HTML5

<body> - Contains visible page content

alt - Alternative text for accessibility

Form Elements and Validation

✅ HTML Best Practices

🏷️ Always Use Semantic Tags

❌ Bad:
<div class="header">
    <div class="nav">...</div>
</div>
✅ Good:
<header>
    <nav>...</nav>
</header>

♿ Accessibility First

❌ Bad:
<img src="photo.jpg">
<input type="text">
✅ Good:
<img src="photo.jpg" alt="Person smiling">
<label for="name">Name:</label>
<input type="text" id="name">

📱 Mobile-First Attributes

❌ Missing:
<head>
    <title>Page</title>
</head>
✅ Complete:
<head>
    <meta name="viewport" 
          content="width=device-width, initial-scale=1.0">
    <title>Descriptive Page Title</title>
</head>

✅ Form Validation

Real-time validation with custom error messages

View Code Example 
function validateField(fieldName, field, errorElement) {
    const value = field.value.trim();
    let isValid = true;
    
    switch (fieldName) {
        case 'email':
            const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
            if (!emailRegex.test(value)) {
                isValid = false;
            }
            break;
    }
    return isValid;
}

Interactive project category filtering

filterBtns.forEach(btn => {
    btn.addEventListener('click', function() {
        const filter = this.getAttribute('data-filter');
        
        projectCards.forEach(card => {
            if (filter === 'all' || card.getAttribute('data-category') === filter) {
                card.style.display = 'block';
            } else {
                card.style.display = 'none';
            }
        });
    });
});
